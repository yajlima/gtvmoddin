# Current / Best Percent

Changes the in-game percentage to show **current% / best%**, for example `12% / 40%`.

- The left number updates live while you play, with 3 decimals by default (e.g. `7.412%`).
- The right number is your saved normal-mode best for the level.
- When you pass your best, the right number updates right away, during that same attempt.
- Practice mode, start positions and platformer levels never bump the best.
- Shows even if the game's own Show Percentage option is off.

Turn it on or off, and pick 0-3 decimal places, in the mod's settings.
